Getting started: how to get a free API key

Get your key (about 1 minute)

  1. Go to z.ai and create a free account, or log in.
  2. Open the API keys page: z.ai/manage-apikey/apikey-list
  3. Click Create to make a new API key. Any name is fine.
  4. Copy the key straight away. Z.ai shows it in full only once. It has two parts joined by a dot.
  5. Paste it in the API key box below and press Save.

Tips

  • Choose a model from the dropdown at the top right of the chat. GLM-4.7-Flash is the newest, but it sometimes shows a 429 "busy" error. For easy tasks and everyday conversation, use GLM-4.5-Flash.
  • Thinking mode (the checkbox below): the model reasons step by step before it answers. It is slower but better for coding, maths and tricky questions. Turn it off for quick, everyday chat.
  • Your key stays in this browser. On a host with sync set up, your chats follow you to any device once you paste the same key there.
